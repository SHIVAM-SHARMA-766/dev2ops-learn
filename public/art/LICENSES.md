# Art & icon licenses

All assets here are open-licensed and free for commercial use. They are vendored
locally (served from this site, not a CDN) so the site stays $0 and works offline.

## Hand-crafted (this repo)
The illustrated SVG scenes (shipping container, laptop, server, database, cloud,
isometric box) are drawn in `src/islands/widgets/illustrations.jsx`. MIT, same as
this project.

## Brand logos — `logos/`
Populate with `node scripts/fetch-art.mjs` (needs network).

- **Devicon** — technology logos (Docker, Node, Postgres, Redis, Nginx, Linux,
  Git, Python, Go, Kubernetes, …). MIT License. https://devicon.dev
  Logos remain trademarks of their owners; used here descriptively/educationally.

## UI / object icons — `icons/`
- **Tabler Icons** — MIT License. https://tabler.io/icons

## Other free packs you can add (vendor the SVGs into this folder)
- **unDraw** — flat scene illustrations, free, no attribution required,
  commercial OK. Recolor to the accent. https://undraw.co
- **Simple Icons** — brand icons, CC0 (mind trademarks). https://simpleicons.org
- **Storyset (Freepik)** — animated illustrations; free **with an attribution
  link**. If used, add the credit to the page footer. https://storyset.com
- **LottieFiles** — free JSON animations; check each file's license.
  https://lottiefiles.com

Keep this file in sync when adding assets.
